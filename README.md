Alfredo's Shopping List App

A simple and responsive shopping list web application built with HTML, CSS, and Bootstrap.This application allows users to view features, pricing, add and manage items they want to buy.

Features

Add Items: Easily add new products or groceries to your shopping list.
Delete Items: Remove items once they are bought or no longer needed.
Interactive UI: Clean layout with basic styling for desktop and mobile devices.

Technologies Used

HTML: for structure
CSS: for styling and responsive design
Clean UI: Minimal and lightweight design styled with CSS.

Getting Started

Clone or download the repository to your local machine.
Open the project folder.
Open index.html directly in your favorite web browser to view the app.

File Structure
